🧠 LLM From Scratch

This project demonstrates how to build a Large Language Model (LLM) from scratch, step by step — covering everything from tokenization to transformer architecture, training, and inference.

The goal is to learn how modern LLMs (like GPT) work internally by implementing the components yourself.

🚀 Features

Custom Tokenizer: Implemented from scratch (including vocabulary, encoding, decoding, and BPE-style merging).

Transformer Architecture: Coming soon — self-attention, feedforward layers, and positional embeddings.

Training Pipeline: Will include dataset loading, batching, and loss optimization.

Educational Focus: Clean, minimal, and easy-to-follow implementation for learning.
